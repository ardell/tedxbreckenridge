{%- comment -%} A single social glyph, drawn to the design system's 1.6px line weight. The one place these paths live — used by facets/social-row.html and by the footer's social icon buttons in _layouts/default.html. The svg is aria-hidden: every caller wraps it in a link that carries the accessible name, so the glyph itself must not be announced. Params: type — instagram | youtube | facebook | linkedin | flickr | mail (default) px — width/height in px (default 20). Named `px`, not `size`: on an include's parameter drop `size` resolves to the number of parameters passed, so it can never be read back as a caller-supplied value. {%- endcomment -%} {%- assign icon_px = include.px | default: 20 -%}
