{%- comment -%} Site-wide ticket-sales popup (Facets kit). A centered modal + dimmed backdrop that pushes ticket sales. Rendered once on every page from _layouts/default.html, guarded by an "unless page.ticket_popup == false" check so any page can opt out via front matter and the whole feature can be killed site-wide from _config.yml `defaults`. Self-contained: markup, styles, and behavior all live here. To remove the feature entirely, delete this file and its include line in default.html -- nothing else references it, and no CSS/JS is left behind. Dismissal is remembered in localStorage for DISMISS_DAYS days (see the script), after which the popup returns -- urgency escalates as the event nears. Styled with main.css design tokens only (main.css is the one stylesheet loaded on every page); it does NOT depend on kaleidoscope.css, which some pages lack. {%- endcomment -%}
